모호한 점 4 — 「내용 미정」 선언이 IR에만 있을 때 (도식 판정기 J7)

회색 = Human·판정기가 보지 않는 것흰색 = Human·판정기가 보는 것

실제 그림 (v3.8 CLI로 렌더)

Agent가 IR에 배송 묶음을 certainty:"dashed"(내용 미정)로 적었다. CLI는 그대로 짧은 점선 테두리로 그린다.

경우 1 — 최종 보고에 미정을 글로 적음 → J7 PASS

① IR (Agent가 씀)

"id":"grp2","label":"배송 묶음",
"certainty":"dashed"
→

② 그림

배송 묶음 테두리 = 점선
→

③ 최종 보고

배송 묶음은 내용 미정: 반품을
배송에 포함할지 아직 정해지지 않음
→

④ 판정기가 보는 것 = ②+③

점선 + 「미정」 글이 있음 → 선언 있음

경우 2 — IR에만 있고 보고에는 없음 → J7 FAIL (지금 판정 기준)

① IR (Agent가 씀)

"certainty":"dashed"
← 선언은 여기에만 있음
→

② 그림

배송 묶음 테두리 = 점선
→

③ 최종 보고

도식을 완성했습니다.
(미정 언급 없음)
→

④ 판정기가 보는 것 = ②+③

점선은 있는데 이유가 없음 → 「선언 없는 점선」

Human도 같은 처지: 그림에 점선만 보이고, 무엇이 왜 미정인지는 IR을 열지 않으면 모른다.

질문: 경우 2를 어떻게 볼까

  • A (권고): FAIL이 맞다. Human이 보는 곳(그림 안 글 또는 최종 보고)에 무엇이 미정인지 적어야 한다 → skill에 규칙 추가.
  • B: PASS로 본다. 판정기가 IR(회색 ①)까지 읽어 선언을 확인한다.
  • C: 보류. 본 실험 뒤 정한다(그동안 판정 기준은 A).
